# 설계: 카드 초기화 v1

작성일: 2026-07-24
상태: 승인 대기
브랜치: `claude/pn532-nfc-i2c-wiring-o9x7b1`

## 목적

관람이 끝나 회수한 카드를 **빈 상태로 되돌려 새 관람객에게 재발급**할 수 있게 한다.
운영자가 카드를 리더에 올려놓으면 현재 내용을 보여주고, 2단계 확인을 거쳐 사용자
메모리를 완전히 소거한다. 아까 발급/도장 테스트 중 반쯤 써져 손상된 카드를 복구하는
용도도 겸한다.

발급 스테이션·도장 리더와 같은 공유 카드 로직(`card.py`)과 "순수 로직 + 얇은 I/O"
패턴을 재사용한다.

## 범위

포함:
- 카드 현재 내용 요약 표시 → 2단계 확인 → 사용자 메모리 완전 소거 → 읽기 검증
- 우리 카드 / 빈·손상 카드 / 남의 태그 모두 내용을 보여준 뒤 처리(손상 복구 겸용)
- 요약 로직의 단위 테스트

제외 (나중에 논의):
- 도장만 리셋(같은 사람 재시작) — 이번은 전체 wipe만
- 전시관 명단 중앙화(`exhibits.json`) — 별도 스펙
- Supabase, NTAG 쓰기 비밀번호

### 공유 상수 (card.py)

```python
EMPTY_NDEF = bytes([0x03, 0x00, 0xFE, 0x00])  # 빈 NDEF 메시지(내용 없음, 한 페이지)
```

`decode_ndef_uri(EMPTY_NDEF)`는 `None`, `has_ndef(EMPTY_NDEF)`는 `False`여야 한다
(빈 상태 판정과 정합). 소거 후 발급 스테이션은 이 카드를 빈 카드로 보고 확인 없이
재발급한다.

## reset_logic 인터페이스 (순수)

- `describe_card(url: str | None) -> str`
  - `url is None` → `"빈 카드 또는 해독 불가"`
  - 우리 카드(`stamp_logic.is_our_url(url)`가 True) → 닉네임을 URL 디코드해 요약:
    `"닉네임: 철수 · ID: 04E14301544803 · 방문: 1,2"` (방문 없으면 `방문: 없음`)
  - 그 외(BASE 아님) → `"우리 카드 아님"`

`n` 디코드는 `urllib.parse.unquote`로 표시용으로만 하며, 카드에는 아무것도 쓰지 않는다.

## 초기화 흐름 (한 장, 반복 루프)

1. `"카드를 리더에 올려놓으세요"` → 카드 감지
2. 사용자 메모리 읽기 → `decode_ndef_uri` → `url` → **`describe_card(url)` 출력**
3. **2단계 확인**: `초기화할까요? (y/N)` → `y`, 그리고 `확인: UID 뒷 4자리 입력` → 일치.
   둘 다 통과해야 진행. 하나라도 아니면 취소(카드 미변경).
4. **완전 소거**: 사용자 페이지 `4`~`69`를 `00 00 00 00`으로 쓴 뒤, 페이지 4에
   `EMPTY_NDEF`를 써서 "빈 NDEF"로 마무리. (페이지 쓰기는 재시도 로직 사용.)
5. **읽기 검증**: 다시 읽어 `decode_ndef_uri`가 `None`이면 성공 → `초기화 완료`.
6. **카드 제거 대기** 후 다음 루프.

소거 범위 4~69는 우리가 굽는 최대 URL(닉네임 20자 한글, ~65페이지)을 덮는다.
CC(페이지 3)와 UID(0~1), 잠금 바이트(2)는 건드리지 않는다.

## 에러 / 엣지 처리

| 상황 | 처리 |
|---|---|
| 확인 거부/불일치 | 취소, 카드 미변경 |
| 소거 쓰기 실패(재시도 후에도) | 에러 + 재실행 안내. 부분 소거는 재실행으로 완료(멱등) |
| NTAG 계열 아님(교통카드 등) | `ntag2xx_write_block` 실패 → 에러 메시지, 카드 손상 없음 |
| 루프 중 예외 | `try/finally`로 카드 배출 + main 루프 per-card catch-all(도장 리더 패턴) |
